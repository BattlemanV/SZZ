# Отчёт СЗЗ

Программа для Windows, которая по расчётам **УПРЗА «Эколог»** заполняет раздел
отчёта по санитарно-защитной зоне (СЗЗ).

На входе — три отчёта «Эколога», сохранённые в Word (`.docx`):

| Отчёт | Расчёт в «Экологе» |
|---|---|
| МР | расчёт рассеивания (максимальные концентрации) |
| СГ | расчёт средних (среднегодовых) концентраций |
| СС | расчёт среднесуточных концентраций |

На выходе — два файла рядом с отчётом МР:

- **`Отчет СЗЗ (<имя МР>).docx`** — раздел 3.1 (выделяющиеся вещества и источники
  выбросов), текст с итоговыми выбросами по критериям ПДК м/р, с/с, с/г и ОБУВ,
  таблица 3.1 «Перечень загрязняющих веществ» и таблица 5.2 «Уровни загрязнения
  атмосферного воздуха в контрольных точках»;
- **`Отчет СЗЗ (<имя МР>) — приложение.docx`** — отчёт МР целиком, первый лист и
  результаты расчёта СГ и СС; точки во всех результатах отсортированы по номеру.

## Установка

Скачайте установщик `Отчет_СЗЗ_установка_<версия>.exe` из раздела
[Releases](../../releases) и запустите его. Python ставить не нужно, права
администратора не требуются.

При установке можно указать каталог справочника веществ «Эколога» (`VocW`, обычно
`C:\integral.ltd\VocW`). Он необязателен: без него нормативы берутся из отчёта МР,
а классы опасности — из файла `классы опасности.csv` в папке программы.

Программа не подписана цифровой подписью, поэтому Windows при первом запуске может
показать предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

- **Перетащить файлы на ярлык.** Выделите отчёты МР, СГ и СС и перетащите их на
  ярлык «Отчёт СЗЗ» на рабочем столе. Программа сама определит, какой файл
  какой (по шапке отчёта), и сохранит результат рядом с МР.
- **Окно программы.** Двойной щелчок по ярлыку: укажите файлы вручную, при
  необходимости — другой шаблон или каталог справочника.

Подробная инструкция — [installer/Инструкция.html](installer/Инструкция.html)
(после установки она есть в меню «Пуск»).

Оформление отчёта задаёт шаблон [`отчет выход.docx`](отчет%20выход.docx):
многоточия в тексте программа заменяет числами по порядку.

## Для разработчика

Нужен Python 3.12+ (сборка проверена на 3.14).

```
pip install -r requirements.txt
python szz.py                      # окно программы
python szz.py мр.docx сг.docx сс.docx   # как перетаскивание на ярлык
python app.py --mr мр.docx --sg сг.docx --ss сс.docx   # командная строка
python -m unittest discover -s tests
```

Проверки на настоящих отчётах «Эколога» лежат в `tests/fixtures`, но в репозиторий
не входят (это данные заказчиков) — без них соответствующие тесты пропускаются.

Сборка установщика (нужны [PyInstaller](https://pyinstaller.org) и
[Inno Setup 6](https://jrsoftware.org/isinfo.php)):

```
pip install pyinstaller
powershell -ExecutionPolicy Bypass -File installer\build.ps1
```

Результат — `installer\output\Отчет_СЗЗ_установка_<версия>.exe`; версия задаётся
в [installer/szz.iss](installer/szz.iss) (`AppVersion`).

### Устройство

| Модуль | Что делает |
|---|---|
| `mr2projekt/mr_parser.py` | разбор отчётов «Эколога»: источники, выбросы, ПДК, группы суммации, результаты по точкам |
| `mr2projekt/vocw.py` | чтение справочника веществ VocW (таблицы Advantage `.ADT`) |
| `mr2projekt/generator.py` | заполнение текста и таблицы 3.1 по шаблону |
| `mr2projekt/table52.py` | построение таблицы 5.2 |
| `mr2projekt/appendix.py` | приложение с исходными отчётами |
| `mr2projekt/pipeline.py` | весь процесс: отчёты → документ |
| `szz.py`, `drop.py`, `gui.py`, `app.py` | точки входа: exe, перетаскивание, окно, командная строка |
